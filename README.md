# Around The U.S.

## Descripción

Around The U.S. es un proyecto de práctica donde se muestra una galería de tarjetas con imágenes de distintos lugares del mundo. El usuario puede editar su perfil, agregar nuevas tarjetas con lugares, darles "me gusta" y eliminarlas.

Este proyecto forma parte del Sprint 6 del bootcamp de desarrollo web de TripleTen, y su objetivo es practicar la manipulación del DOM con JavaScript: recorrer arrays, generar contenido dinámico y manejar eventos.

## Funcionalidad

- Visualización de tarjetas de lugares con imagen y nombre.
- Array `initialCards` con los datos iniciales de 6 lugares (nombre e imagen).
- Recorrido del array con `forEach()` para verificar los datos en consola.
- Ventanas emergentes (popups) para editar el perfil y agregar nuevas tarjetas.
- Botones de "me gusta" y "eliminar" en cada tarjeta.

## Tecnologías utilizadas

- HTML5
- CSS3 (metodología BEM)
- JavaScript (ES6+)
- Git y GitHub para control de versiones
